# Linux — 2.4.11

[Download Linux x64](https://github.com/dustindwayne/artificial-negligence/releases/latest/download/ArtificialNegligence-Linux.tar.gz).

Extract the complete archive and run `ArtificialNegligence.x86_64` from its folder. Keep the Data folder, UnityPlayer.so and the other bundled files together. Executable permissions are included; if your extractor removes them, mark the executable as runnable in your file manager.

Native Unity Mono x86-64 desktop build. It requires a graphical Linux desktop and compatible OpenGL/Vulkan drivers. Keyboard controls match Windows. The Linux build uses the same release source, campaign, characters, items, UI, keyboard actions and gamepad actions as the other desktop builds. Linux controllers use Unity Input System device mappings; Windows uses XInput. Physical controller and Linux distribution compatibility still require playtesting.
